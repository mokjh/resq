# RESQ map schema (`content/wN/mM/map.json`)

The C# `MapCompiler` (`game/Assets/Resq/Sim/Runtime/Content/MapCompiler.cs`) is the single source of truth. This page lists what it reads; when in doubt, read the compiler. Rule meanings are in `specification/02_RUNTIME_RULES.md`, and rule readings made while implementing are in `DECISIONS.md` (22–23 Oct).

Maps are generated by Python scripts in `tools/maps/` with `mapkit.py`. Put World 2–5 sections in `Map.extra[...]` (passed through verbatim).

Coordinates are `[x, y]`, with the origin at the southwest. The grid is 32×24 and the first row in `rows` is north. A **cell spec** is either a legend-char string (`"RS"`), a list `[[x,y],…]`, or a rect `{"x0","y0","x1","y1"}`.

## Core (all worlds)

| Section | Fields |
|---|---|
| `rows`, `legend` | Legend char → `elev` (mm), `code` (terrain id), optional `init_depth` (mm), `cond` (mm²/s, default 100,000), `solid` (no hydraulic links). W2 adds `fuel` (default **1000** when fire is enabled — author `0` for roads and water), `wetness`, `building`. |
| `regions` | `{name: cell spec}` |
| `sources` / `sinks` | `{id, at, rate}` (mm³/s) |
| `nodes` | `{id, at, flags[], capacity, safe_depth, berths, water_at, dock_min_depth, dock_max_depth, vehicle_slots}`. Flags: `assembly junction dock shelter evacuation vehicle_parking staging`. |
| `edges` | `{id, from, to, ticks, class: ground/water/cable, slots (2), step_free, enabled, current (1000), max_depth, min_depth, sample (cell spec), via [[x,y]], tags[]}`. Tags with rule meaning: `debris_reopenable`. Any tag can feed an `edge_transfers` metric. |
| `sockets` | `{id, tool, at, zone, orientations, platform (cell spec), edge, intake, outlet, node, destination, power, links [[[x,y],[x,y]]…]}`, plus the per-world fields below. |
| `power` | `nodes: [{id, fixed_supply}]`. `links`: `[a, b]`, or `{from, to, relay: "relay:NN"}` for a relay-made link (W4). Every relay socket must bind exactly one link. |
| `infrastructure` | `{id, power, demand, priority, region, max_depth (100), max_heat (300), nodes[], gates_dock, support (W3), producer (W5)}` |
| `vehicles` | Fixed vehicles: `{id, kind: fixed_bus/crawler/winch/skiff, node, seats, slots}` |
| `groups` | Map-side node binding for contract groups: `{id, start, assembly, pickup}` (pickup defaults to `<id>_pickup`). |
| `routes` | `{id, from, to, class: ground/water/cable}`; used by `route_available` objectives. |
| `roles` | `{role: {sources/edges/groups/stores/infrastructure/regions/supports/runouts/tides/lava_sources/cooler_sockets/shelters: [...]}}`. Every contract event `target_role` must resolve to something for its operation kind. |
| `class_overrides` | `{wide/compact: {section: replacement}}`. Arrays of objects with `id` merge per id. This is how the compact layout swaps the primary dock. |

## World 2 — fire

- `fire: {enabled: true, wind_regions: [region…]}`. Wind codes: 1 W, 2 E, 3 N, 4 S, 5 NE, 6 SE, 7 SW, 8 NW (fire spreads toward that direction).
- `stores: [{id, elev, area, volume}]` are finite water tanks. They are extra water nodes; sprinklers draw from them.
- Sockets:
  - `firebreak`: `cells` (1–8 fuel cells; no buildings).
  - `sprinkler`: `cells` (1–4), `store`, `power`.
- Event roles: `ignite_region`, `add_heat`, `set_wind` and `set_region_cooling` target `regions`. `warn_resource` targets `stores`.

## World 3 — stability, runout, winch

- `supports: [{id, base_stability (400), static_load (0), nodes[], edges[] (where residents load it), collapse_nodes[], collapse_edges[]}]`
- `runouts: [{id, source_support?, segments: [{id, edges[], nodes[], cells, next[], delay (10), settle (200)}]}]`. The first listed segment starts the runout. The graph must be acyclic.
- Sockets:
  - `brace`: `support` (≤ 3 per support; slopes take none).
  - `winch`: `node` (cabin start, an end of the cable), `edge` (a `class: cable` edge), `power`, optional `support` (destroyed on collapse).
  - Any socket with `support` breaks when that support collapses.
- Event roles: `set_stability_loss`, `set_support_load`, `tremor` and `warn_support` target `supports`. `release_avalanche` and `warn_runout` target `runouts`.
- Crawler: socket `tool: crawler` with `node`; 6 seats, 2 ground slots.

## World 4 — tides, relays

- `tides: [{id, datum (mm), cells (sea boundary grid cells), conductance (2,000,000), max_transfer, initial_level, track? [[tick, level]…], period?}]`. Sea head = datum + level. An event ramp (`set_tide_segment` 0–3 → 0/600/1000/800 mm) and a fixed `track` are mutually exclusive per controller.
- `relay` sockets: `platform` cells and a power link `{from, to, relay}`. The link drops above 50 mm and reconnects by itself at ≤ 40 mm.
- Event roles: `set_tide_segment` targets `tides`. `set_current_multiplier` (500–2000) targets `edges`. A `warn_support` bound to `infrastructure` is advisory.
- Dock berths are reserved at departure.

## World 5 — lava, coolant, shelters

- `lava: {segments: [{id, cells, edges[] (crossings closed unless Dormant/Crusted), nodes[] (unsafe at heat ≥ 600), delay (100), next: ["id" | {to, delay ≥ 50}]}], sources: [{id, segment}]}`
- `coolant_stores: [{id, charges (2), capacity (8)}]`
- An infrastructure entry with `producer: {store, feedstock (6), ticks (100)}` is the cooling works: power demand ≥ 1, default priority 40.
- Sockets:
  - `cooler`: `segment`, optional `coolant_store` (refill source), `enabled` (false = locked until `enable_cooler_socket`).
  - `shelter`: `node` (flag `shelter`, capacity 1–6, never `evacuation`), optional `region` (external hazard area).
- Event roles: `advance_lava` and `warn_reheat` target `lava_sources` (the event needs ≥ 100 ticks of warning). `enable_cooler_socket` targets `cooler_sockets` (socket ids). `enable_shelter_hazard` targets `shelters` (socket ids).
- The milestone `first_cooled_crossing_closed` has a `target` role with `lava_sources`.

## Strategy steps (`content/wN/mM/strategies/*.json`)

Each step is `{"t": <operation tick>, …}` with one action:

| Action | Fields |
|---|---|
| `place` | socket, optional `orientation` |
| `move` | socket, `to` (socket) |
| `enable` / `disable` | socket |
| `vehicle` | socket or fixed id, optional `group` and `pickup`, `to`, `evacuate` (true) |
| `group` | `to`, `evacuate` (true) |
| `priority` | infra id or socket, `value` |
| `cool` | cooler socket |
| `refill` | cooler socket, `store` |
| `end` | optional `confirm_failure` |

Times are **operation** ticks; Relaxed runs the scenario clock at half speed (see the W1-M3 note).
