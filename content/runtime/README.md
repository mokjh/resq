# Runtime content implementation

`schemas/` contains generated draft-2020-12 closed schemas for the immutable content contract in specification/03_RUNTIME_CONTRACTS.md. Regenerate through `python3 -B tools/content/generate_contracts.py`. The generator owns data-shape declarations only and does not implement gameplay algorithms. Generated readers use the same schema definitions as the exported files.

The no-engine `Resq.Content` assembly provides immutable typed records, a strict UTF-8/canonical JSON reader, ordinal entity ordering, SHA-256 content/graph/layout identities, the runtime envelope loader, and structural/reference validation. `ContentCompilation.Compile` accepts explicit runtime definitions; `Load` validates an exact envelope and hash. Authoring defaults must be explicit in that input. The compiler returns role-resolved immutable event operands. `Resq.Editor.Content.ContentCompiler.WriteBundle` validates the exact output bytes and writes a new file without overwriting previous artifacts.

The `fixtures/` directory is synthetic compiler test input. It is not an authored campaign mission, reference replay, playable level, proof of hazard-time solvability, or accepted C01 evidence. `python3 -B tools/content/build_fixtures.py` reproduces it. Actual 25-mission runtime geometry remains assigned to the separate AUTHOR tasks; no production mission output is claimed here.

Native EditMode suite: `runtime_content` in `Resq.Content.Tests`. The registered runner suite is `runtime-content`. Its three NUnit cases carry exact `check-c01` assertion case IDs. After durable native XML, the automation entry point can invoke `Resq.Editor.Content.ContentCompiler.WriteEvidence(xmlPath, packetPath)` from `Resq.Content.Editor`; it derives case outcomes only from the actual XML.

Structural reachability may include legal deployable links. It cannot prove actual hazard-time solvability or all paths' simultaneous equipment affordability; mission REPLAY tasks must execute the real shared simulator. Visual collision/geometry qualification and the recipe's frozen world-anchor inspection remain separate AUTHOR/art checks.

Challenge expansion creates an isolated immutable copy, applies each declared operation in order, rehashes modified layouts and reruns the full structural compiler. `CompiledContent.ChallengeVariants` exposes each effective version and hash; base content stays intact. Alternate Dock binds the frozen recipe's `{group_id}_pickup` node through matching named-route endpoints/waypoints and nav-node role targets. It requires an existing named pickup and legal alternate dock and fails closed with `CHALLENGE_PICKUP_BINDING` when that mapping cannot be derived. It changes neither the resident start/assembly nor the physical base graph. Actual challenge replays remain required.
